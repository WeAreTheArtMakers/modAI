# Accessibility
Test semantic landmarks, accessible names, keyboard order, visible focus, contrast and reduced-motion behavior. Inspect real UI before changing it. Use native controls when practical; ARIA does not replace correct HTML.
Ensure menus and dialogs expose their state, trap focus only when necessary and return focus on close. Associate labels and errors with inputs. Check narrow layouts and zoom. Automated gates cover only part of accessibility; record manual checks and remaining limitations.
