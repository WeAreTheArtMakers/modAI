# Web3 Engineering
Identify chain, network, framework, ABI and RPC configuration from project context. Do not assume mainnet. Develop and test on a local chain or testnet before production transactions.
Validate addresses, decimals, chain IDs, signatures, gas estimates, events and reverted transactions. Handle pending, confirmed, replaced and failed states in UI. Never expose private keys. For contract changes inspect access control, reentrancy, external calls, arithmetic and upgrade assumptions. Use existing contract tests and request a focused security review when relevant. Skills grant no transaction permissions.
